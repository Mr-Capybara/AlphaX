# 阶段计划

`PLAN.md` 只记录已经和人类确认过的阶段计划。agent 不应自行写入新的阶段计划，也不应在未确认的情况下调整计划范围。

## PLAN-0002 · AlphaForge 部署与验收

**确认日期** 2026-11-10

### 目标

在 `methods/AlphaForge/` 部署官方实现，用真实 A 股日频行情跑通因子挖掘和动态组合，交付可复跑的命令、因子池和验证结果，为后续统一对照做好准备。[AlphaForge 官方实现](https://github.com/DulyHao/AlphaForge)

### 执行步骤

1. **固定代码和环境。** 建立独立仓库，锁定官方提交、Python 和依赖版本。记录运行入口及必要的本地适配。
2. **接入真实行情。** 优先复用 PLAN 1 的 Tushare 沪深 300 快照，核对字段、成分区间、复权和收益标签。记录 AlphaForge 的数据要求与 AlphaGen 的差异，选定一组用于短跑的训练与验证区间。
3. **分两阶段短跑验收。** 用固定种子和缩短预算运行因子挖掘，保存非空、可单独读取的公式池。再用官方动态组合入口读取该因子池，在验证区间输出有限的预测指标。分别记录两阶段的运行命令、耗时和产物位置。

### 完成条件

凭记录能重跑两阶段流程，并分别取得**挖掘产出的公式池**和**动态组合的验证结果**。其他候选方法部署完成后，再统一确定评测口径和正式运行预算。
